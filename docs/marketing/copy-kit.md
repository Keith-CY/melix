## Product Paragraph

Melix is a native local AI workspace for Apple Silicon. It combines model
registry management, local server sessions, chat, LoRA and QLoRA fine-tuning,
benchmarking, and evaluation in one CLI-backed macOS App. Operators can take a
dataset from package to adapter to derived model to comparison evidence without
leaving the machine.

## LoRA-Focused Paragraph

Melix makes LoRA training feel like a repeatable product workflow instead of a
collection of scripts. Choose a base model, point Melix at a local or Hugging
Face dataset, train a LoRA or QLoRA adapter, activate it as a derived model, and
run the same benchmark and evaluation surfaces against both base and adapted
models.

## README Insert

### LoRA Training Loop

Melix is built around a local adaptation loop:

```bash
swift run melix lora train --model-id <base-model> --dataset-uri <dataset> --adapter-name <name> --training-mode qlora
swift run melix lora activate --model-id <base-model> --adapter-path <train_lora.adapter.json> --alias <derived-model>
swift run melix eval compare --model-id <base-model> --target-model-id <derived-model> --suite mmlu
```

The same workflow is available from the native macOS App, including training
configuration, adapter history, activation, comparison, and export surfaces.

## Release Note Draft

Melix includes a productized LoRA workflow across the CLI and native macOS App.
Operators can train LoRA or QLoRA adapters from local packages or supported
Hugging Face datasets, activate adapters as named derived models, compare base
and derived outputs through evaluation, and export evidence. The Window UI
surface exposes training controls, saved jobs, adapter-backed activation,
comparison, derived-model removal, and screenshot-backed acceptance evidence.
