# Runbooks

This directory stores executable operating procedures for Melix.

Use runbooks for:

- local startup flows
- debugging steps
- recovery actions
- manual verification sequences
- operational checklists

A runbook should let a new contributor or agent diagnose and recover a known class of problem without relying on unwritten context.
