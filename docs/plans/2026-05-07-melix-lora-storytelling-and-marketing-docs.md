# Melix LoRA Storytelling And Marketing Docs

## Goal

Create a concise documentation and copy kit that explains, introduces, and
promotes Melix with reproducible command evidence and native App screenshot
evidence, with LoRA training as the primary product story.

## Source

- User request: create a series of documents and text for Melix explanation,
  introduction, and promotion, paired with actual commands and App screenshots,
  especially emphasizing LoRA training.
- Product truth: `docs/current-status.md`
- LoRA operator truth: `docs/runbooks/phase-8-lora-adapter-workflow.md`
- Benchmark, evaluation, and LoRA comparison truth:
  `docs/runbooks/benchmark-matrix-evaluation-and-lora.md`
- Desktop training-studio truth:
  `docs/plans/2026-05-04-issue-347-lora-training-studio.md`

## Scope

- Add a marketing/documentation section under `docs/marketing/`.
- Write a product introduction that stays aligned with the current shipped
  Melix capability surface.
- Write LoRA-focused narrative copy that explains the dataset to train to
  activate to compare workflow.
- Write reusable copy blocks for a README, website hero, short announcement,
  social posts, and release notes.
- Preserve actual command evidence from repository-owned LoRA CLI and Window UI
  smoke or acceptance flows.
- Preserve at least one native App screenshot generated by the current App
  renderer and document how to regenerate it.
- Link the new material from the documentation index.

## Non-Goals

- Change runtime behavior, protocol schemas, CLI contracts, or SwiftUI
  production implementation.
- Claim unverified speed, quality, or broad model-family coverage beyond the
  current status and runbooks.
- Replace existing operator runbooks. The new docs should point to them instead
  of duplicating every operational detail.
- Commit generated runtime directories, logs, pid files, or local Melix state.
